# rag-component-lab
## 展望
A research-oriented lab for reproducing methods from RAG papers and turning them into reusable, composable, and evaluable components.

本项目致力于系统性复现 RAG 论文中的方法，并将其中具有通用价值的算法与流程沉淀为可复用、可组合、可评估的组件。项目覆盖文档处理、查询优化、检索、重排序、上下文处理、答案生成、安全防御与效果评估等环节，使不同论文方法能够在统一接口下独立测试、灵活组合和公平比较。

除算法实现外，项目还将尽可能保留论文来源、默认参数、实验配置、数据集说明、评估指标、复现结果及已知局限，形成从论文理解、方法实现、实验验证到工程集成的完整闭环。通过持续积累和迭代，本项目希望逐步构建一个连接 RAG 学术研究与实际应用的开放实验基础，为新方法验证、组件优化和生产框架适配提供统一支撑。
